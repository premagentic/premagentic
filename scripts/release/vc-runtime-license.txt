Microsoft Visual C++ runtime files in bin\

This archive's bin\ folder carries four files of Microsoft's Visual C++
runtime, which ONNX Runtime's Windows library (bin\onnxruntime.dll) needs and
which Windows does not include:

  msvcp140.dll
  msvcp140_1.dll
  vcruntime140.dll
  vcruntime140_1.dll

They are Microsoft's files, version @VERSION@, shipped unmodified. They were
taken from the Microsoft Visual C++ 2015-2022 Redistributable (x64) @VERSION@:

  SHA-256 @SHA256@
